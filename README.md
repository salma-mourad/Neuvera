# Neuvera

Plateforme web d'analyse EEG assistée par l'IA (Flask, MNE, scikit-learn, TensorFlow).

## Contexte

Neuvera est notre projet de fin d'études, réalisé en équipe de trois
à la Faculté des Sciences Ben M'Sik (Université Hassan II).

Ce dépôt contient ma propre version du projet. Je la reconstruis à partir
du code de l'équipe, avec une architecture revue et plusieurs améliorations :
prétraitement unifié entre l'entraînement et l'application, analyse de toutes
les époques du signal, et évaluation des modèles par sujet.

**Statut :** en cours de développement.
